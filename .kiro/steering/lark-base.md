# 飞书 Base 插件开发

开发时请参考以下 SKILL 文件（位于 `docs/skill/` 目录）：

1. **lark-base-sdk-guide.md** — SDK 架构与全模块 API 速查
2. **lark-base-field-types.md** — 字段类型与接口对照表
3. **lark-base-dev-patterns.md** — 编码规范与常用开发模式

如果 SKILL 信息不全，请参考源文档仓库：https://github.com/Lark-Base-Team/js-sdk-docs
